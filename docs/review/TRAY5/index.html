TRAY5: update window and installer windows, three options

Review only. The owner chooses; nothing here is shipped. Every window is a real screenshot of the real web app (the page the tray opens) with the service answers mocked; each option is a prototype patch in patches/, and no app code is changed in this branch. The title bar of each window is drawn by this page (the page cannot show the OS frame); the content below it is the screenshot. Installer shots are the same web page in an installer host: Windows Installer, the macOS installer and Linux package managers cannot be rendered here, so no screenshot is the native thing (see REPORT.md).

Theme Scaling Option C uses the Windows light or dark colours (a native dialog cannot follow Phosphor).
