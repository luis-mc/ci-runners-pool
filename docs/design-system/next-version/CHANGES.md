- C1: UX-72 and component 15: no table cell is cut by the style. The grow columns no longer end in an ellipsis (`overflow: hidden`, `text-overflow`): a page gives a value made for one line (a workflow is its file name with the path as hover text, the run number has its own fit column, a reason is a few words with the whole line under its button, a branch is shortened in its text by component 56), and a value that still does not fit wraps at a word or anywhere, so the row grows; a cell never covers the next cell or the action column. The weight of a grow column scales its minimum width instead of its share (`--ds-cell-grow-min` times `0.75 + 0.25 * weight`); `--ds-cell-grow-min` no longer says 'cut with an ellipsis'. The v2 text still allows the cut, so this is proposed here and the DOM layout rule `clipped-text` (`scripts/design/dom-layout.ts`, guard in `e2e/tests/web-console/ux-table-cells.spec.ts`) checks it (ux-rules.md, components.md, tokens.md; CRSP210). The UX-72 text itself is the LOOK40 wording (D14, D15); this entry keeps the guard and the grow-column widths.
- C2: content.md gains One-line row words: the short form of each wait reason, the workflow as its file name and the *Run* column (content.md; CRSP210).
- C3: content.md gains Run insights words: the Jobs tab, its segments, the Run elsewhere filter, the Do next, Waits, Timeline, Tests and Guardrails screens, the action wizard and the Job and Run page insight panes (content.md; CIX22).
- C4: a field name in a row of fields (`.ds-field-grid .ds-field__label`) wraps instead of ending in an ellipsis, so the DOM layout rule `clipped-text` holds on the machine page and Settings (components.css; CRSP208, found when CRSP210 joined the screens of CIX and main).
- C5: content.md gains the CIX23 words: the tray entry Open weekly digest, the finding action Hide for 7 days with its busy word and messages, the Settings, Data section CI run insights (Update period, its three choices, Runs between updates) and the cost warning's title and fix (content.md; CIX23). No rule, token or component changed.
