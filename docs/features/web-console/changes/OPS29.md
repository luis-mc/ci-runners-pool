The machine page says one thing about taking jobs. Before, the State fact read the drain state (`state`), the Now line and its note read the agent's last report (`accepting`, `pause_reason`), and the button read the drain state again, so after Stop new jobs the page said "not taking jobs" in State and "Taking jobs" in Now, and before it said Paused in Now for a machine that was online (the agent's report lags a setting the controller has just written, and a machine that has not got its settings yet reports `paused`). Now the State fact, the Now line, its note and the header button all read `taking` from the controller (machines R5.62): taking jobs, or the reason (Not taking jobs for a stop from the console, Paused for the mode or the tray, On battery, Quiet hours, Busy, Needs a base image, Disk low, Offline). While a stopped machine still runs jobs, the State fact keeps "Finishing N jobs (up to M min)". The Pause on battery switch under Always is off and disabled with the reason "Always ignores the battery." and the line under it is not repeated; the saved value is not changed. The state note is not dismissible. Reasoning: the controller owns the settings and the drain, so it decides everything it wrote (offline, stopped, mode, tray, battery) and asks the agent only for what the agent alone knows (load, base image, disk, quiet hours); the page then has no second source to disagree with.
