The keyboard moves focus through the whole page: Down and Up (and `j` and `k` outside a text box) go through every button, link, input and list item in page order, with a hand-over at the first and last list item. A radio group is one stop and a multi-line box keeps its own arrows. The command palette opens with focus in its search box, filters as you type and moves through its results with the same keys. The shared parts are `ArrowNavigation` and `SearchList` (R5.4, R5.5; UX-57).
