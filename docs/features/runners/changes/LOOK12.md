The tool lists of the layers carry words for the Images screen: a title and a one-line "pick it when" for each optional layer, and the job labels that ask for it. The base tools and their pinned versions are read from the embedded `images/linux-base/Dockerfile`. The layers chosen for an image are stored per machine and OS (R5.32); the contents of the Images tab are in caches R5.55.
