The owner said the console does not look enough like a Linux terminal. This page shows six looks, each drawn as the same Overview screen in its dark theme (the default, UX-60) and its light theme. Pick one; it then goes into the design system's next version as a CHANGES entry, and the owner approves it before it ships.

Every option keeps the rules: all text monospace, a status is a word, a glyph and a colour (UX-58), only the focused control glows (UX-59), one primary action with Cancel on the left (UX-4, UX-24), text meets WCAG 2.2 AA in both themes (UX-17, checked by script), and 360 px works (UX-16).

Options marked tokens only change colour, radius and type values and nothing else, so UX-55 allows them as a theme. Options marked one component change also change how a card or the header is drawn (box titles, a status line, command blocks); that change goes into components.md once, and every screen gets it from the shared part.
